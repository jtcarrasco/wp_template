# WP Template

Classic WordPress starter with a minimal custom theme, running on Lando.

## Quick Start

```bash
lando start
bash scripts/setup.sh
```

Open http://wp-template.lndo.site

## Requirements

- [Lando](https://lando.dev) v3.21+
- Docker Desktop (or Docker Engine on Linux)

## Demo Content

- Sample blog post
- About page
- WP Starter theme (minimal, classically structured)
